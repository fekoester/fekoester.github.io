FitzHugh–Nagumo Networks

A dense recurrent network of FitzHugh–Nagumo neurons classifying MNIST and Fashion-MNIST, trained by backpropagation through time and by local three-factor plasticity.

One FitzHugh–Nagumo neuron, in its phase plane

The network in this project is built from these units. With little input current the neuron rests. A kick beyond threshold fires one large excursion, a spike, and it returns. With more current the rest state turns unstable and the neuron fires periodically. Click anywhere in the plane to start a trajectory there.

regime: –v-nullclinew-nullclinetrajectory

v̇ = v − v³/3 − w + I, τẇ = v + a − b·w with b = 0.8, τ = 12.5. The regime label comes from the eigenvalues at the fixed point.
