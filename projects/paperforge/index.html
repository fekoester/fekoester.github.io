PaperForge

An early pipeline that turns technical PDFs into structured, evidence-checked knowledge cards: every extracted claim must be backed by a verbatim quote from the page.

GitHub ↗

On this page

  1. Overview
  2. Live demo

Stack / topics

  • LLMs

Implemented so far: page-level PDF text extraction, LLM card extraction, verification of evidence quotes against the source, and a CLI.

Interactive example

No quote, no claim

PaperForge asks an LLM for structured knowledge cards, and every card must carry a verbatim quote from the page as evidence. The check is deliberately dumb: is the quote really in the source text? Paraphrases and invented quotes are rejected. Edit a quote to try it.

Source page (example passage, invented for this demo)

We train echo state networks with 200 nodes on the Mackey–Glass series. With a ridge readout, the one-step normalised error on the held-out segment is 0.031. Raising the spectral radius above 1.1 made the closed-loop forecast diverge in four of five seeds. All runs use five random seeds and the same input scaling.

The reservoir has 200 nodes.

Whitespace and quote marks are normalised before matching; everything else must match exactly. A rejected card is dropped, or sent back to the model.
