What I work on

  • Delay-based reservoir computingOne nonlinear node plus delayed feedback as a high-dimensional computer: memory capacity, information processing capacity, eigenvalue analysis, photonic hardware.
  • Attention-enhanced reservoirsState-dependent readouts on fixed dynamics: smaller reservoirs, multiple attractors, better closed-loop forecasts.
  • Efficient language modelsReservoir and hybrid architectures for language: what can be left untrained, and what that buys at inference.
  • LLM training dynamicsTraining as an action principle: exposure laws, why data reweighting is zero-sum, and optimizer metrics that change the learning path. Working notes →
